# Investigations

Files here are dated evidence, not current guidance.

When creating or materially updating an investigation, state:

| Field | Required content |
|---|---|
| Question | The scoped issue being investigated. |
| Evidence scope | The sources and time range examined. |
| Status | Open, decided, superseded, or closed. |
| Current owners | The canonical homes of accepted conclusions, or `None yet`. |
| Open decisions | Unresolved choices, or `None`. |
| Closure outcome | `Pending` while open; when closed, promoted guidance and its owner, routed work, removed stale progress, and why retained evidence remains useful. |
